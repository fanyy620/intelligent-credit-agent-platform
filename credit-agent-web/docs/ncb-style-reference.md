## 真实品牌视觉特征（取样结论）

- **行标**：圆形印章式图案——正红圆环内含图案化「南」字（天圆地方构图），
  红为鲜亮朱砂红，像素取样主值 **#E30000**（邻近 #E10000–#E50000）。
- **行名**：「NCB」与「南洋商業銀行」为**深藏青**书法/衬线字，
  取样家族 #1E074E / #281350 / #301467，取 **#2B1665** 为主用值。
- **气质**：白底、红印、藏青字——鲜亮正红与深靛蓝的高对比，
  **品牌色中没有金色**；官网友好留白多、正文灰阶细字、导航红/藏青。
- **品牌叙事**：1949 年庄世平创办于香港，「红色」港资银行；
  宗旨「以客为先、以礼待人」，原则「信誉第一、服务至上」，
  愿景「做最了解中国人的外资银行」。

## 映射到界面的规则

1. **侧边栏**：深藏青渐变（`#241254 → #150A3C`），行标区白字藏青行名；
   菜单激活态 = 正红渐变条（对应官网红色主导航），不使用金色边框。
2. **顶栏**：白底 + 藏青页面标题（对应官网白底页头）。
3. **行标（自绘）**：正红实心圆章 + 白色衬线「南」字——与真实 logo 的
  「白底红圈篆字」构图不同，属风格演绎而非复制。
4. **登录页**：藏青渐变底 + 白卡片（顶部 3px 正红边），红章 + 藏青行名 +
  「NANYANG COMMERCIAL BANK」小字，副标题体现对公中台定位。
5. **数据看板**：统计卡取 正红 / 藏青 / 绛红（#9E1B47）/ 石墨蓝灰 四色，
   意图条用 红→藏青 渐变；不再使用金色。
